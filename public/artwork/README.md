# Bergwiesen-Hintergrund

`../alpine-meadow.webp` wurde am 09.11.2026 für den ausdrücklich beauftragten Startbildschirm mit OpenAI-Bilderzeugung erstellt. Das generierte Motiv stellt eine Zentralschweizer Alpenlandschaft mit Kühen dar, keine dokumentarische Aufnahme eines bestimmten Ortes. Es enthält keine Patienten-, Interview- oder Therapiedaten und keine medizinischen Inhalte.

Es ist eine dekorative Appgrafik gemäss F16 in `docs/DECISIONS.md`. Videos, MP3s und andere Therapie-/Dialogmedien bleiben lokal auf dem Tablet. Die Hand-/QR-Anleitung ist in `src/welcome.js` als SVG/Browseranimation implementiert; es wird kein Animationsvideo geladen.
